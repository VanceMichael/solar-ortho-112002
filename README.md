# 光伏巡检影像覆盖与派单凭据的演练来源

这里提供独立来源的本地合成记录，与实际单位、个人和线上业务无关。

## 本地运行

使用 Node.js 22.23.4。只使用 Node.js 自带的运行库。

执行 `npm test` 检查合成来源的接口。执行 `npm start` 启动来源，默认监听 `127.0.0.1:4100`，可通过环境变量 `PORT` 调整端口。访问根路径可看到来源名和当前回放阶段。

## 接口资料

| GET 路由 | 来源约定 |
| --- | --- |
| `/source/imagery` | capture 是拍摄身份；band 可有 IR 与 RGB。index 声明取件名、姿态和定位解，received 标记本轮影像站的实物交付，可带饱和或阴影标记。 |
| `/source/geometry` | footprint 为平面格集合，hot 为供应方给出的格内热斑候选。相同 capture 换 solve 后是同一原件的另一定位解释。area 给出组件内毫米级有效与遮挡矩形。 |
| `/source/assets` | install 是按格与半开时间范围提供的板位事实。温度达到 issueFrom 即可生成复查凭据。accept 是现场接单回执。coverage-rule 给出板面范围与合格覆盖比例。 |

查询参数 `offset` 是从零开始的页偏移，`limit` 默认 3，取值 1 至 100。响应中的 `records` 含 `record` 来源记录键、`availableFrom` 首次出现的回放阶段、`kind` 记录类型、`payload` 业务字段。来源记录键与业务身份分别定义。`next` 为下一页偏移，末页为 `null`。回放阶段中的记录按到达顺序可查。

控制员通过 `POST /control?stage=2` 切换到第 2 阶段，服务会保留更早已可查的记录。每次换阶段后按根路径返回的 `stage` 确认切换成功。原件通过 `GET /original/文件名` 领取，阶段内尚不可领时返回 404。原件文件和摘要记录在 `originals/` 与来源索引。

area 以组件上的毫米坐标给有效矩形 validRects 和需扣除的遮挡矩形 maskedRects，顺序为左、上、右、下。板面范围和合格覆盖比例由 coverage-rule 给出。影像是可读 PGM/PPM，几何与温度由来源侧人工校验记录提供。

覆盖规则定义板面平面和最低比例。area 记录组件内的有效和遮挡矩形，坐标顺序为左上右下，矩形右边和下边不包含在范围中。图像原件可用常见 PGM/PPM 解码。

## 消费侧：覆盖判定与派单凭据

`app/` 是调度员一侧的判定与查询系统，只依赖 Node.js 自带运行库：

- `app/client.mjs` 分页拉取三处来源记录，领取原件并留存 sha256 摘要。
- `app/store.mjs` 把记录归一化为状态：拍摄、定位解、装机区间、规则与接单回执。
- `app/engine.mjs` 判定：缺件、观测资格（交付/定位/饱和/阴影）、按定位解分列的覆盖视图与现行视图、复查凭据、定位修订通知。
- `app/monitor.mjs` 每轮刷新重建状态并比对增量；判定由记录确定性推出，重复刷新不产生重复凭据。
- `app/server.mjs` 现场查询接口；`app/main.mjs` 按回放阶段走查并打印判定变化。

判定口径：

- 索引先到而实物未到时按缺件上报；波段带饱和或阴影标记的观测无资格，其余板位与其他有效观测不受影响。
- 覆盖按定位解分列，同一拍摄只取一版解进入一次判定，绝不把两版解的板位解释拼在一起；现行视图对每次拍摄取最新一版解。
- 窗口内同板位的有效矩形合并，重叠只算一次，遮挡矩形扣除；只有遮挡没有有效矩形拆分的，不以更大外框计入。
- 温度达到 issueFrom 且观测有资格即出复查凭据，与覆盖窗口无关；窗口外补拍可出凭据但不反填当天完整覆盖。
- 热斑按拍摄时刻的生效装机记录归到组件；板位换板后，旧热像不作为新板的复查依据。
- 定位修订把热斑移到相邻板位时，旧派单留存，变更通知交原接手人；相邻板位满足口径时另出独立可领的凭据。

运行方式：先 `npm start` 启动来源（默认 `127.0.0.1:4100`），再 `npm run inspect` 逐阶段走查，或 `npm run query` 启动查询服务（默认 `127.0.0.1:4200`，`SOURCE` 环境变量可改来源地址）。

查询接口（均需先 `POST /refresh`）：

| 路由 | 内容 |
| --- | --- |
| `GET /captures`、`/captures/{id}` | 各波段交付状态与缺件 |
| `GET /cells/{cell}` | 板位的每次有资格/无资格观测及原因、现行与各解视图的覆盖比例和未覆盖区域、相关凭据 |
| `GET /panels/{panel}` | 组件的装机区间、归入它的观测与凭据（换板后旧热像不计入新板） |
| `GET /orders`、`/orders/{id}` | 凭据列表；单证的拍摄时刻、姿态、定位解、footprint、热斑、生效装机、原件摘要、接单与修订通知 |
| `GET /notices` | 定位修订通知（旧派单留存、交原接手人、新凭据独立可领） |
